## Packages
react-webcam | Webcam component for React
@tensorflow/tfjs-core | Core TensorFlow.js library
@tensorflow/tfjs-backend-webgl | WebGL backend for TensorFlow.js
@tensorflow-models/pose-detection | Pose detection models
recharts | Charting library for analytics
framer-motion | Animation library for smooth transitions
lucide-react | Icon library (already in base but good to be explicit)
clsx | Utility for constructing className strings conditionally
tailwind-merge | Utility for merging Tailwind CSS classes

## Notes
The application requires webcam access for the workout tracking feature.
We will use MoveNet (Lightning) for lightweight pose detection.
Authentication is session-based via the provided API.
